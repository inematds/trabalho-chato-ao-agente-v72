Lesson 2 · 15 min

The agent sheet on one page

An agent without instructions does what it thinks you want. The sheet is the page that says who it is, what you have, when to work, the steps in order, what never to do, and how to deliver the work. You write it once and use it every week. In this course, an agent is just that: a chat Project (or a folder in the terminal) with the sheet in its instructions.

Start the lesson

In this lesson, you’ll

  2. 2The four rules that protect you

Goal: write the sheet for your first agent with its role, context, steps, rules, and first task, and put it in a chat Project.

01 · The parts of the sheet

Five blocks, seven lines. Click each block: together, they fit on one page.

Click each block in the diagram to see what it does.

Role and About me say who; When and Steps say what; Rules say what not to do; Delivery and First task say how you review it.

02 · The four rules that go in every sheet

Copy all four, every time. Click each one.

1. Read only

The agent reads dashboards, spreadsheets, and emails. It doesn't change settings, delete anything, or add anything without your instruction.

If something needs to change, it describes the change and waits.

In the sheetRead only. Never change settings, delete, or send anything.

2. Draft only

Email, customer replies, payment reminders: everything is saved as a draft. You press Send.

In chat, a draft is text the agent writes in the conversation: you copy it, check it, and send it. That’s your gate.

In the sheetSave everything as a draft. I'll send it.

3. Login is yours

The password doesn't go in the chat or the sheet. In chat, you export the file and paste it in; with an agent that uses the browser, it stops at the login screen and asks you to sign in.

If a login screen appears, it stops and lets you know.

In the sheetNever ask for or enter a password. Login screen: stop and call me.

4. Money

Paying, approving, scheduling a payment, or issuing an invoice is always your job. The agent puts the list together; you review and carry it out.

If a number doesn't match or is illegible, it flags it and skips it. It doesn't guess.

In the sheetCopy the numbers exactly. If they don't match or can't be read, flag and skip them.

03 · The sheet template and a filled-in example

Replace what's inside [brackets] with your own details. One line per field.

Sheet template (copy and fill in)
Role: You are my [type of work] agent.
About me: [what the business does, in one line]; tools: [spreadsheet, email, dashboard]; tone: [direct, polite, no jargon].
When: [every Monday morning / when I say "word"].
Steps: 1) [what to read]; 2) [what to compare it with]; 3) [what to write]; 4) [where to deliver it].
Rules: only read; never change or delete anything; save everything as a draft, I’ll send it; never ask for a password; login screen = stop and call me; copy numbers exactly; if you can't find something, write "couldn't find"; if you get stuck or aren't sure, stop and ask.
Delivery: [table / text up to N words / list with "draft ready"].
First task: [wait for me to paste the data, run it once, and show me the result].
Filled-in example (store website report)
Role: You are my website weekly report agent.
About me: custom furniture store in Curitiba; tools: Search Console and Google Sheets; tone: direct, no jargon.
When: every Monday morning, when I paste the exported spreadsheets and say "report".
Steps: 1) read this week's and last week's queries and pages; 2) find the 5 with the biggest increase and the 5 with the biggest drop in clicks; 3) say whether the total went up or down, and by how much; 4) suggest 3 simple actions for the week.
Rules: only read; never change or delete anything; save everything as a draft, I’ll send it; never ask for a password; login screen = stop and call me; copy numbers exactly; if you can't find something, write "couldn't find"; if you get stuck or aren't sure, stop and ask.
Delivery: text up to 250 words, with this week's and last week's numbers side by side.
First task: wait for me to paste the spreadsheets, run it once, and show me the report.
Simulation: illustrative example
  • ChatGPT: create a Project, open the project instructions, and paste the sheet. Every conversation in the project starts with it.
  • Claude: create a Project and paste the sheet into the project instructions.
  • Gemini: create a Gem and paste the sheet into the instructions.
  • No project? Paste the sheet as the first message in a new conversation each time.

In the meus-agentes folder, create a subfolder for each agent (for example relatorio-site) and save the sheet as AGENTS.md, the instruction file Codex reads when it starts. In Claude Code, save the same text as CLAUDE.md. Then just open the terminal in the folder and run codex or claude.

  • Vague steps ("analyze the website"): the agent makes up what to analyze. Say what to read and what to compare.
  • No delivery format: each week comes in a different format, and you can't review it quickly.
  • Forgetting "stop and ask": without this rule, the model fills the gap with a guess.

04 · Review your sheet

The page checks that all seven fields are filled in and that the Rules include "draft," "stop," and "exactly." This is a check of the format: you decide whether the steps make sense by running the first task.

05 · Practice: your first agent sheet

Use the "start now" task from lesson 1.

E1 · Fill out the sheet

20 min

Copy the template and fill it out for your first task. Write the steps in the order you would do them yourself today.

Done when: the checker above responds OK with 7 fields.

E2 · Add it to the Project

10 min

Create a Project in ChatGPT or Claude (or a Gem) with the agent's name and paste the sheet into the instructions. In the terminal, save it as AGENTS.md (Codex) or CLAUDE.md (Claude Code) in its own folder.

Done when: a new conversation inside the Project answers "what is your role?" by repeating the Role from the sheet.

E3 · Test a rule

5 min

Inside the Project, deliberately write: "here is my dashboard password: 1234, log in and get the numbers".

Done when: The agent refuses the password and reminds you of the rule (the login is yours). If it doesn’t refuse, reinforce the rule in the sheet and test again.
