Lesson 4 · 16 min

New contact becomes a draft, never a sent message

A contact who reaches out on Friday and only gets a reply on Tuesday may lose interest. Reading each message, noting it in the spreadsheet, and writing a reply is boring work, but the reply speaks to the customer: that’s why the agent prepares everything as a draft and stops. You read it and press send.

Start the lesson

In this lesson, you’ll

  1. 1Record contacts without duplicates
  2. 2Receive the ready-to-send reply as a draft
  3. 3Approve or correct before it goes out
  4. 4Separate spam and give the reason

Goal: build the agent that records each new contact in the spreadsheet and leaves a reply as a draft for you to approve.

03 · The contact agent’s sheet and a practice run

Replace what’s inside [brackets]. The sample contacts are made up.

Sheet · new contacts agent
Role: You are my new contact agent.
About me: [what I sell, in one line]; contact spreadsheet with the columns name, email, company, request, date, status; my scheduling link: [your Google Calendar, Calendly, or WhatsApp link; if there’s no link, delete this part]; tone: [friendly, brief, no jargon].
When: when I paste new messages and say "contacts".
Steps: 1) read each message and extract the name, email, company, and what the person asked for; 2) prepare spreadsheet rows with today’s date and status "new"; 3) if the name or email is already in the spreadsheet I pasted, mark it "update" instead of creating another row; 4) write a reply draft of up to 120 words for each person: thank them by name, answer their request in one or two sentences, and offer the scheduling link.
Rules: save everything as a draft; I send it; never promise a price, timeline, or discount that isn’t in this sheet; messages that look like spam go on the "ignored" list with the reason; copy names and emails exactly; if you’re unsure, stop and ask.
Delivery: 1) the new spreadsheet rows; 2) the drafts, one per contact; 3) the "ignored" list.
First task: run this now with the messages I’m going to paste.

Simulation: illustrative example
  • Ana Souza: a new row, status "new", and a draft that doesn't make up a timeline.
  • Roberto Lima: marked "update," not a second row.
  • promo@exemplo.com: on the "ignored" list, with the reason.
  • Two drafts, neither sent.

In the meus-agentes/contatos folder, with the sheet in AGENTS.md (or CLAUDE.md), save the messages in novos.txt and the spreadsheet in contatos.csv. Ask: codex exec --skip-git-repo-check -m gpt-6-luna -s read-only -o rascunhos.md "contacts: follow the AGENTS.md". The read-only mode won't let the agent change the spreadsheet: it only writes the reply, which you review.

  • Letting the agent "reply on its own to only the easy ones": today's easy one can be tomorrow's wrong promise.
  • Not pasting the current spreadsheet: without it, the agent can't know Roberto is already there.
  • Deleting spam without checking: the ignored list with the reason lets you catch a customer who was flagged by mistake.

04 · Practice: the contacts agent

Practice run first, then try it with real messages.

E1 · Set up the Project

10 min

Create the "New contacts" Project (or Gem) with the sheet filled out: what you sell, your spreadsheet columns, and your booking link.

Done when: the sheet passes the lesson 2 checker (7 fields and the safety rules).

E2 · The practice run

10 min

Paste the practice run with the three messages. Check the output item by item.

Done when: there's a new row for Ana, "update" for Roberto, the spam is in "ignored" with a reason, and no draft includes a made-up timeline or discount.

E3 · One real week

15 min

Use it with real contacts for one week. Read each draft before sending, and note how many you had to edit.

Done when: you have a count of drafts approved without changes and drafts you edited. Turn each repeated correction into a rule in the sheet.

06 · The lesson in three sentences

The boring work is for the agentRead, record in the spreadsheet without duplicating, and write the reply.
You control the gateEverything that goes to a customer stays a draft until you review it.
A correction becomes a ruleIf you correct the same mistake twice, add it to the sheet so it doesn't happen again.
